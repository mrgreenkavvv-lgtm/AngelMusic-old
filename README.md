# AngelMusic 🎸

Веб-приложение для учителя гитары в начальных классах и его учеников:
учим ноты в скрипичном ключе и азбуку музыки в игровой форме.

## Что умеет

- **Угадай ноту** — ноты от «ми» малой до «ми» третьей октавы на нотном стане,
  4 варианта ответа, звук гитарной струны, 6 уровней сложности с добавочными линейками.
- **Профи-режим** — 7 кнопок со всеми нотами и кнопка «Ввод»; «Профи 2» — нота и октава.
- **Экзамен по нотам** — открывает учитель: число вопросов, формат ответа, таймер, оценка по 5-балльной шкале.
- **Азбука музыки** — карточки и вопросы: строение гитары и лады, нотный стан и ключ, октава,
  длительности, паузы, доля, метр и размер (2/4, 3/4, 4/4, 6/8), знаки альтерации,
  лад и тональность, громкость и повтор.
- **Тренажёры** — «Найди ноту на грифе», «Собери такт», «Слух» (мажор/минор, выше/ниже, какая нота), тюнер по микрофону.
- **Алмазики и магазин** — алмазики за звёзды, тесты без ошибок, серии дней и экзамен; аватарки, аксессуары, цвет гитары, темы оформления и призы от учителя.
- **Мои успехи** — 15 уровней, звёзды, медали мастерства (бронза, серебро, золото), серия дней, награды.
- **Режим учителя** (ПИН-код, по умолчанию `1234`) — имя ученика, трудные ноты,
  включение уровней и тем, число вопросов, звук, смена ПИН-кода, сброс прогресса.
- Работает на телефоне, планшете и компьютере; после первого открытия — без интернета;
  можно добавить на главный экран телефона как приложение.

Прогресс хранится в памяти браузера на устройстве ученика.

## Как опубликовать на GitHub Pages

1. Создайте репозиторий на GitHub (например, `angelmusic`) и загрузите в него все файлы этой папки.
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите *Deploy from a branch*, ветку `main`, папку `/ (root)` и нажмите **Save**.
4. Через 1–2 минуты приложение будет доступно по адресу `https://<ваш-логин>.github.io/angelmusic/`.

## Запуск на компьютере

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Структура (все файлы лежат в корне репозитория)

```
index.html   — точка входа
style.css    — дизайн (вариант A, яркий игровой)
app.js       — экраны, тесты, экзамен, режим учителя
notes.js     — ноты, уровни, рисование нотного стана
theory.js    — карточки и вопросы азбуки музыки, рисунок гитары
store.js     — прогресс, уровни, серия дней, настройки экзамена
audio.js     — звук гитарной струны, аккорды, гаммы и сигналы
games.js     — тренажёры: гриф, собери такт, слух
tuner.js     — тюнер (микрофон)
shop.js      — магазин: аватарки, аксессуары, гитары, темы
version.json — номер версии для автообновления (менять вместе с APP_VERSION в app.js)
sw.js        — работа без интернета
*.woff2      — шрифты Nunito и Noto Music (лицензия SIL OFL)
```
